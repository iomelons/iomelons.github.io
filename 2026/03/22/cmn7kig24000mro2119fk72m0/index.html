OpenClaw Hexo 博客管理技能使用教程

OpenClaw Hexo 博客管理技能使用教程

基于 Qexo 设计理念打造的智能 Hexo 博客运维助手

📌 一、概述

hexo-blog 是一个基于 OpenClaw 平台的 Hexo 博客全栈管理技能，它可以帮你：

  • ✍️ 文章管理：创建、编辑、删除、发布
  • 🚀 自动化部署：一键部署到 GitHub Pages
  • 💾 备份回滚：自动备份，支持一键回滚
  • 📊 站点统计：查看博客数据
  • 🔄 源码同步：部署后自动同步源码

🎯 二、前置要求

环境要求

要求 说明
OpenClaw 已安装并正常运行
Node.js 16+ 版本
Git 已配置 SSH 密钥
Hexo 已初始化博客

GitHub 配置

  1. GitHub Pages 仓库：用于存放博客静态文件
  2. 源码仓库：用于备份博客源码（可选）

📝 三、基础使用

1. 写文章

指令：写文章：文章标题

效果：

  • 自动创建 Markdown 文件
  • 生成规范的 Front-matter
  • 保存到文章目录

2. 写并发布

指令：写并发布：文章标题

效果：

  • 创建文章
  • 生成静态文件
  • 部署到 GitHub Pages
  • 同步源码到备份仓库
  • 验证部署成功

3. 发布博客

指令：发布博客

当你手动添加或修改文章后，执行此指令完成部署。

🔧 四、进阶功能

1. 草稿系统

写草稿：写草稿：标题

适合先写草稿，之后再发布：

发布草稿：发布草稿：标题

2. 查看站点统计

指令：查看站点统计

显示内容：

  • 文章总数
  • 总字数
  • 标签统计
  • 分类统计
  • 最新更新时间

3. 备份博客

指令：备份博客

功能：

  • 自动备份文章、配置
  • 保存到本地备份目录
  • 保留最近 10 个备份

4. 回滚博客

指令：回滚博客

当你部署出错时，可以恢复到之前的备份版本。

⚙️ 八、Git 仓库配置

技能支持双仓库配置：

仓库 用途 分支
origin GitHub Pages 部署 gh-pages
source 源码备份 main

配置说明

  • origin：推送博客静态文件到 GitHub Pages
  • source：备份博客源码，方便多设备同步

🔔 九、通知功能

技能支持部署后通知（需配置）：

通知方式 说明
Bark iOS 推送
Telegram 消息推送
Pushdeer 多端推送

⚠️ 十、安全规则

  1. 禁止删除核心文件

    • _config.yml
    • package.json
    • themes/ 目录

  2. 部署前自动备份

    • 无需手动确认
    • 保留备份历史

  3. 危险操作需确认

    • 删除文章（提示确认）
    • 回滚操作（二次确认）

🔧 十一、故障排查

问题 解决方案
部署失败 (EPERM) 检查 tool-sandbox 配置
Git 推送失败 检查 SSH 密钥配置
文章未显示 检查 Front-matter 格式
搜索不工作 检查 local-search.xml
主题样式异常 清理缓存 hexo clean
