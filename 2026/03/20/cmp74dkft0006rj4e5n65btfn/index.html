什么是 ClawHub？

ClawHub (https://clawhub.ai) 是 OpenClaw 官方技能注册平台，用于发布、版本管理和搜索基于文本的 Agent 技能（SKILL.md + 配套文件）。

它专为快速浏览和 CLI 友好 API 设计，支持以下功能：

  • 🔍 技能浏览：浏览并渲染 SKILL.md
  • 📤 发布技能：支持更新日志和标签（含 latest）
  • ✏️ 重命名：支持技能重命名而不破坏旧链接
  • 🔀 合并技能：将重复技能合并为规范 slug
  • ⭐ 收藏评论：管理员/版主可以策划和审核技能
  • 🔎 向量搜索：通过嵌入向量搜索而非脆弱的关键词

ClawHub 与 onlycrabs.ai

平台 用途
ClawHub (clawhub.ai) 技能市场 (Skills)
OnlyCrabs (onlycrabs.ai) 灵魂/Soul 市场 (Souls)

Soul 类似于技能的”人格”版本，用于定义 AI 的角色和性格。

常见问题

❌ 技能安装失败

检查：

  1. Node.js 版本是否 >= 16
  2. 是否有网络问题
  3. 技能仓库是否存在
  4. GitHub OAuth 是否授权

❌ 技能不生效

解决：

  1. 重启 OpenClaw Gateway
  2. 检查技能是否在 skills 目录
  3. 查看日志：openclaw logs

❌ 不知道技能名称

解决：
直接对 AI 说：「帮我找一个做 xxx 的技能」
