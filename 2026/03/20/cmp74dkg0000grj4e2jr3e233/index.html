为什么每次重新 init？

由于只推送 public/ 目录（不含源码），每次部署时重新初始化 Git 仓库，确保：

  • ✅ 不会推送 node_modules 等无关文件
  • ✅ 历史记录干净
  • ✅ 强制推送覆盖旧版本
